# Syntechhub Calculator

This Android Studio project completes **Project 1: Simple Calculator App** from the Week 1 task PDF.
For the submission repository, use the task's naming pattern: `Syntechhub_SimpleCalculator`.

## Features

- Addition, subtraction, multiplication, and division
- Decimal input, sign toggle, backspace, and clear
- Chained calculations, divide-by-zero feedback, and input-length validation
- Separate calculation logic in `CalculatorEngine`
- Responsive portrait and landscape layouts

## Run

Open this folder in Android Studio with JDK 17 and Android SDK 35 installed, allow Gradle sync to finish, then run the `app` configuration on an emulator or device. Unit tests are in `app/src/test`.
